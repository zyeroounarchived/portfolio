Case Study 02

Game Theory: Blinkit vs Zepto

Group project for Optimization Techniques (5 students). We studied quick commerce in India, where Blinkit, Zepto and Swiggy Instamart compete, and modeled Blinkit vs Zepto as a 3x3 game. Each company picks one of three strategies: Aggressive Expansion, Margin Optimisation or Premium Focus.

Payoffs are in ₹ crore per quarter and come from public data (order value, fee rates, dark store counts). We treated the game as zero-sum, which is an approximation. Instamart is part of the industry study but not part of the matrix.

Source: public figures · simplified assumptions
Strategy model · Nash equilibrium 
import nashpy as nash
import numpy as np

# Rows = Blinkit, columns = Zepto: [Expand, Margin, Premium]
A = np.array([
    [ 0.8,  3.9,  6.5],
    [ 3.2,  2.4,  4.7],
    [-1.8,  1.4,  2.9],
])
game = nash.Game(A, -A)   # zero-sum

for blinkit, zepto in game.support_enumeration():
    print("Blinkit:", np.round(blinkit, 3))
    print("Zepto:  ", np.round(zepto, 3))
    print("Value:  ", round(float(blinkit @ A @ zepto), 3))

# Output:
# Blinkit: [0.205 0.795 0.   ]
# Zepto:   [0.385 0.615 0.   ]
# Value:   2.708

Result

The game has one equilibrium. Blinkit plays Aggressive Expansion about 20% of the time and Margin Optimisation about 80%. Zepto plays Aggressive Expansion about 38% and Margin Optimisation about 62%. Neither company gains by changing its mix alone.

Premium Focus is never used by either side, because another strategy pays at least as much against every choice the opponent can make. The value of the game is about ₹2.7 crore per quarter in Blinkit's favor.

Machine Learning Pipeline

Credit Card Fraud Detection

Step 1. Load the data. Only 492 of 284,807 transactions are fraud (0.1727%), so the classes are very unbalanced.

~/fraud/load_data.py
Source: public benchmark dataset 
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, average_precision_score
from imblearn.over_sampling import SMOTE

df = pd.read_csv("creditcard.csv")
print(df.shape)
# Output: (284807, 31)

Step 2. Split first, then scale. test_size=0.2 sends 20% of rows to the test set. stratify=y keeps the 0.17% fraud rate in both parts. The scaler learns its mean and spread from the training rows only, so no information from the test set leaks into training. Correlations with the 'Class' column are also checked on the training rows only.

~/fraud/split_and_scale.py 
X = df.drop('Class', axis=1)
y = df['Class']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)
X_train, X_test = X_train.copy(), X_test.copy()

# Fit on training rows, then apply the same scaling to the test rows
scaler = StandardScaler()
cols = ['Amount', 'Time']
X_train[cols] = scaler.fit_transform(X_train[cols])
X_test[cols] = scaler.transform(X_test[cols])

correlations = pd.concat([X_train, y_train], axis=1).corr()['Class'].drop('Class').sort_values()

Step 3. Balance the training data with SMOTE. For each fraud example, SMOTE finds its nearest fraud neighbors and creates new, similar fraud rows. The test set is never touched.

~/fraud/resample_smote.py 
smote = SMOTE(random_state=42)
X_train_resampled, y_train_resampled = smote.fit_resample(X_train, y_train)

print(f"Before SMOTE: {y_train.value_counts().to_dict()}")
# Output: {0: 227451, 1: 394}

print(f"After SMOTE: {pd.Series(y_train_resampled).value_counts().to_dict()}")
# Output: {0: 227451, 1: 227451}

Step 4. Train a logistic regression and test it on the untouched test set. Accuracy is not used here: a model that never flags fraud would still be 99.8% accurate. Instead we look at recall (how many frauds are caught), precision (how many alerts are real fraud) and PR-AUC.

~/fraud/evaluate.py 
model = LogisticRegression(max_iter=1000)
model.fit(X_train_resampled, y_train_resampled)

pred = model.predict(X_test)
scores = model.predict_proba(X_test)[:, 1]

print(classification_report(y_test, pred, digits=3))
print("PR-AUC:", round(average_precision_score(y_test, scores), 3))

Generative AI / Hiring Infrastructure

Zero-Bias Resume Parser

Open Parser ↗

This app reads a resume PDF and sends it to Gemini 3.8 Flash. It returns a list of technical skills in a fixed format, so reviewers can compare candidates quickly.

The model is told to leave out names, contact details, photos, addresses and other personal details, so the output shows skills only. The full PDF is still sent to Gemini, so this limits what the reviewer sees, not what the model reads.

Stack: Next.js App Router, Tailwind CSS v4, and Google Generative AI.

Live Demonstration

PDF in, list of skills out, with personal details left out of the result.

Next.js API Route

~/app/api/parse/route.ts 
import { GoogleGenerativeAI, SchemaType } from '@google/generative-ai';

export async function POST(request: Request) {
  try {
    const formData = await request.formData();
    const file = formData.get('resume') as File;
    const buffer = Buffer.from(await file.arrayBuffer());

    const model = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!)
      .getGenerativeModel({
        model: 'gemini-3.8-flash',
        generationConfig: {
          responseMimeType: 'application/json',
          // The reply must match this shape: { "skills": ["Python", ...] }
          responseSchema: {
            type: SchemaType.OBJECT,
            properties: {
              skills: { type: SchemaType.ARRAY, items: { type: SchemaType.STRING } },
            },
            required: ['skills'],
          },
        },
      });

    const result = await model.generateContent([
      { inlineData: { data: buffer.toString('base64'), mimeType: 'application/pdf' } },
      'List the technical skills in this resume. Do not include names, contact details, addresses or other personal details.',
    ]);

    return Response.json(JSON.parse(result.response.text()));
  } catch (err) {
    return Response.json({ error: 'Could not read this resume.' }, { status: 500 });
  }
}

Creative Essay

The art of giving up.

We live in a world that worships persistence. We hear it in classrooms, in sports, in offices and in advertisements: keep going, never quit, winners never give up. Quitting is seen as a weakness and stopping is seen as failure. And yet... everyone has quit something somewhere, sometime, somehow.

To abandon one path is not always to fall into failure; sometimes it is to recognize that a path was never truly ours. Kierkegaard once wrote that despair is to live at odds with one's own self. In this light, quitting becomes not cowardice but reconciliation: a turning back toward what is authentic.

To persist without hope is not tenacity—it's inertia. Thus, giving up is not always surrender. It can be a higher form of courage: the ability to stop, to relinquish, to make space for something unimagined.

The sunk cost fallacy. The more time, money, or energy we've invested in something, the harder it feels to walk away... But the past cannot be recovered. The only choice we truly control is the present moment, and the direction we step into next.

To give up is not to stop living, it's to start living differently. And sometimes, thats just the art of giving up.

Analytical Documentation

Constitutional Erosion

The philosophical core of the constitution lies in The Preamble, the blueprint which organizes the Law into four core values- Justice, Liberty, Equality and Fraternity.

The judgment [K.S. Puttaswamy v. Union of India (2017)] introduced a constitutional framework that governs any state action infringing on privacy, forcing a re-evaluation of government operations and legislative necessity. The Court established a three-fold test that any State action encroaching upon privacy must satisfy: Legality, Legitimate Aim, and Proportionality.

Erosion of Federalism in not-so recent trends and major legislative actions, particularly the Goods and Services Tax (GST) and changes in the Concurrent List, suggest that India’s federal structure is experiencing a centralizing tilt towards a more unitary system.

Ever since the Independence of India, literacy rate has been consistently rising. A consequence of which is the criticism of the Constitution and Law as a whole... The continuous threat to privacy, despite its clear recognition as a Fundamental Right, illustrates the erosion of the Constitution.

The true Erosion is not in the text, but in the political class's disregard for the 'Principled Distance' of secularism and the 'Proportionality Test' of privacy, effectively treating the Constitution as obsolete in practice.
